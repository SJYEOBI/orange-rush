ORANGE RUSH / 오렌지 러시
v0.2.0 · Unity 6 · Windows 64bit · 2~4인 온라인 파티 게임

바로 실행
1. Windows 실행판 ZIP을 전부 압축 해제합니다.
2. OrangeRush.exe를 실행합니다. exe만 따로 옮기면 실행되지 않습니다.
3. 방장은 이름과 포트를 입력하고 [새 방 만들기]를 누릅니다.
4. 참가자는 방장 주소와 같은 포트를 입력하고 [친구 방 참가하기]를 누릅니다.
5. 방장이 로비에서 NORMAL(기본) / HARD(하드)를 고릅니다. 선택은 모두에게 적용됩니다.
6. 2~4명이 모이면 방장이 [룰렛 돌리고 시작하기]를 누릅니다.

하드 모드와 복붙 방지
- 두벌식 한글 자판에서 '오렌지'를 반복해 입력합니다. 한/영 전환은 필요하지 않습니다.
- 글쇠 순서: D H F P S W L (ㅇ ㅗ ㄹ ㅔ ㄴ ㅈ ㅣ).
- 단어를 끝까지 입력하면 자동으로 1회가 올라갑니다. Enter를 누를 필요가 없습니다.
- 입력판에 지금까지 입력한 부분과 다음에 누를 글쇠가 표시됩니다.
- 오타가 나면 진행 중인 단어만 초기화됩니다. Backspace로 한 단계 되돌릴 수 있습니다.
- 일반 텍스트 입력창이 없고 실제 글쇠의 눌림만 읽으므로 Ctrl+V, Shift+Insert,
  마우스 붙여넣기, 한글 문자열 주입으로 점수가 올라가지 않습니다.
- 서버도 한 단어에 필요한 7개 글쇠의 순서와 입력 시각을 검사합니다.
- 점수 단위는 기본 '타', 하드 '회'입니다. 동점 통과·탈락 규칙은 같습니다.
- 첫 턴은 7초이며 하드는 7 → 9 → 11 → 13초처럼 매 턴 2초씩 증가합니다.
- 난이도는 방장만 로비에서 바꿀 수 있습니다. 한 판 더! 이후에는 다시 선택할 수 있습니다.
- 통신 방식이 업데이트되어 v0.1.0과 함께 플레이할 수 없습니다. 모두 v0.2.0으로 업데이트하세요.

온라인 접속
- 같은 PC에서 테스트: 여러 실행 창을 열고 주소 127.0.0.1로 참가합니다.
- 같은 공유기: 방장 대기실에 표시되는 내부 IPv4 주소로 참가합니다.
- 서로 다른 인터넷: 방장 공유기의 TCP 7777 포트를 방장 PC로 포워딩하고,
  참가자에게 방장 공인 IPv4 주소 또는 해당 주소를 가리키는 도메인을 알려줍니다.
- 다른 포트를 쓰면 공유기 설정과 참가자 입력도 똑같이 바꿔야 합니다.
- Windows 방화벽 창은 사용자가 직접 확인하고 게임의 네트워크 접근을 허용해야 합니다.
- 이 버전은 IP 직접 접속 방식입니다. 자동 매칭, 방 코드, 중계 서버, 자동 NAT 통과는 없습니다.
- 통신사 공유 주소(CG-NAT), 학교/회사 망 등 포트 개방이 어려운 환경에서는
  현재 방식으로 외부 접속이 안 될 수 있습니다. 공인 주소가 필요합니다.
- 접속 시간 초과 시 주소, 방장 실행 여부, 포트, 방화벽과 공유기 설정을 확인합니다.

게임 규칙
1. 룰렛이 첫 주자 1명을 무작위로 선정합니다.
2. 첫 턴은 7초. 기본은 8초, 9초, 10초… 매 턴 1초씩, 하드는 9초, 11초, 13초… 매 턴 2초씩 증가합니다.
3. 해당 주자만 [준비 완료]를 누를 수 있습니다. 3초 카운트다운 후 시작합니다.
4. 기본은 스페이스바를 눌렀다 떼며 연타하고, 하드는 오렌지를 직접 타이핑합니다.
5. 직전 성공 기록 이상이면 통과합니다. 동점도 성공입니다.
6. 성공한 주자는 오른쪽의 살아 있는 다른 플레이어 카드를 마우스로 눌러 지목합니다.
7. 목표보다 적게 치면 탈락합니다. 남은 플레이어 중 다음 주자를 무작위로 뽑습니다.
   목표 기록은 유지되며, 제한 시간은 다음 턴에 기본 1초/하드 2초 증가합니다.
8. 탈락한 사람은 관전합니다. 마지막 한 명이 우승합니다.
9. 방장은 [한 판 더!]로 대기실로 돌아갈 수 있습니다. 다시 7초부터 시작합니다.
10. 첫 주자는 기준 기록을 세웁니다. 첫 기준은 0타입니다.

연결과 판정
- 방장 프로그램이 게임 서버 역할을 합니다. 별도 서버 설치나 계정은 필요하지 않습니다.
- 룰렛, 점수, 시간 종료, 지목, 탈락은 방장 측에서 결정해 전원에게 전송합니다.
- 다른 사람의 타수 입력, 본인 지목, 중복 타수 패킷과 시간 종료 이후 타수는 거부합니다.
- 시간 종료 판정은 방장에게 입력이 도착한 시각 기준입니다. 네트워크 지연은 영향을 줄 수 있습니다.
- 게임 도중 연결이 끊긴 참가자는 탈락합니다. 무응답 연결 감지는 약 15초입니다.
- 게임 중간 참가/재접속은 지원하지 않습니다. 다음 대기실에서 참가할 수 있습니다.
- 방장이 탈락해도 방은 유지됩니다. 방장이 프로그램을 종료하면 방도 종료됩니다.
- 게임 창을 작게 줄여도 화면 비율에 맞춰 조정됩니다. 다른 창에 포커스가 있으면 연타가 입력되지 않습니다.
- 친구끼리 즐기는 프로토타입입니다. 키보드 자동 입력 방지나 상용 부정행위 방지 기능은 없습니다.

Unity에서 수정하기
1. Unity Hub에서 OrangeRush 프로젝트 폴더를 추가합니다.
2. 권장 에디터: Unity 6000.0.59f2 (Unity 6.0).
3. Assets/Scenes/OrangeRush.unity를 열고 Play를 누릅니다.
4. 게임 화면은 OrangeGame.cs가 실행 시 자동 구성합니다.
5. Assets/Scripts/GameRules.cs: 게임 규칙.
6. Assets/Scripts/NetworkRoom.cs: TCP 네트워크 전송.
7. Assets/Scripts/OrangeGame.cs: 화면, 입력, 룸 동기화.
8. Assets/Editor/BuildGame.cs: Windows 빌드 설정과 자동 빌드.
9. 외부 유료 에셋이나 별도 멀티플레이 서비스 계정은 필요하지 않습니다.
10. 한글은 Windows의 맑은 고딕을 사용하며 폰트 파일을 재배포하지 않습니다.

명령줄 빌드 예시
Unity.exe -batchmode -nographics -quit -projectPath "프로젝트 절대경로" -executeMethod BuildGame.Build -logFile "로그경로"
기본 실행 파일 출력: 프로젝트/Build/OrangeRush.exe
ORANGE_BUILD_PATH 환경 변수로 실행 파일 출력 경로를 변경할 수 있습니다.

검증
- 순수 규칙과 실제 TCP 연결에 대한 자동 검사 55개 통과.
- Windows 실행 파일에서 방장 1명과 TCP 테스트 참가자 3명의 4인 연결 확인.
- 실행 파일에서 룰렛, 7~10초 턴 진행, 타수 동기화, 지목, 탈락, 최종 우승,
  [한 판 더!]의 대기실 복귀를 확인했습니다. 테스트 참가자는 같은 PC에서 접속했습니다.
- Unity Windows x64 빌드 성공 및 실제 실행 화면 확인.
- 서로 다른 외부 인터넷 회선에서의 접속은 이 작업 환경에서 검증하지 않았습니다.
- Verification 폴더에 규칙/통신 검증용 .NET 9 콘솔 프로젝트가 포함되어 있습니다.
  dotnet run --project Verification/GameRules.Tests.csproj
